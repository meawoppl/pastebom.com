# Source attribution

The s-expression parser and schematic model modules in this crate are extracted
from the MIT-licensed `kct` crate in the KiCadmium plugin in
`agent-portal-plugins/kicadmium/kct`. That crate is a Rust port of
[RJ Walters' kicad-tools](https://github.com/rjwalters/kicad-tools).

Source repository revision: `5b9c3372482dbf52c3a971abc8c6ad8f8d586847`.

The original copyright and permission notice is preserved in
[LICENSE-kicad-tools](LICENSE-kicad-tools). Module documentation retains upstream
porting notes. This extraction excludes the CLI, board model, geometry engines,
network clients, and automation subsystems.
